🦷 Cikarang Smile Dental Care — Template Website & Sistem Booking Klinik Gigi

Purwarupa website profesional dan modern untuk klinik gigi yang dilengkapi dengan Simulasi Estimasi Biaya Perawatan dan Sistem Reservasi Jadwal Otomatis ke WhatsApp.

Dikembangkan oleh Terlahir Manusia Web Development sebagai standar solusi digital bagi klinik kesehatan, estetika, dan praktik dokter gigi di Cikarang & sekitarnya.

✨ Fitur Utama

Desain Medis Modern & Responsif: Tampilan bersih dengan palet warna Teal & Cyan yang menenangkan pasien, dioptimalkan untuk layar smartphone maupun desktop.

Katalog Layanan & Harga Transparan: Menampilkan jenis perawatan populer (Scaling, Tambal Laser, Behel, Cabut Bungsu, Bleaching, Gigi Anak) lengkap dengan tombol pilih jadwal cepat.

Simulasi Kalkulator Estimasi Biaya: Pasien dapat mencentang kombinasi perawatan untuk melihat perkiraan total biaya secara real-time dan langsung memasukkannya ke formulir booking.

Form Booking Otomatis ke WhatsApp: Mengubah data isian pasien (Nama, Status Pasien, Tanggal, Sesi Jam, dan Keluhan) menjadi format pesan WhatsApp yang rapi dan siap kirim ke admin klinik.

Profil Tim Dokter & Jadwal Praktik: Informasi dokter umum maupun spesialis (STR/SIP) beserta jadwal praktik harian.

Testimoni Pasien & FAQ Interaktif: Membangun kepercayaan calon pasien baru dengan ulasan nyata dan accordion tanya-jawab.

Mobile Sticky Action Bar: Tombol akses cepat Booking dan WhatsApp yang selalu terjangkau di bagian bawah layar HP.

🛠️ Teknologi yang Digunakan

HTML5 Semantik

Tailwind CSS (via CDN) — Styling responsif dan modern tanpa konfigurasi rumit.

Vanilla JavaScript (ES6+) — Logika kalkulator dinamis, animasi scroll reveal, counter statistik, validasi formulir, dan integrasi URL WhatsApp API.

Google Fonts (Plus Jakarta Sans & Inter) & Font Awesome 6.

🚀 Panduan Deploy Cepat ke Vercel (Untuk Link Demo)

Agar tautan demo bisa langsung dibuka oleh calon klien lewat HP:

Siapkan folder proyek dan simpan file HTML utama sebagai index.html beserta file README.md ini.

Push folder proyek ke repositori GitHub (atau gunakan Vercel CLI).

Buka vercel.com, klik Add New Project, lalu pilih repositori tersebut.

Klik Deploy (tidak perlu pengaturan build command karena menggunakan HTML/CSS/JS statis).

Dalam hitungan detik, tautan demo siap dibagikan ke WhatsApp calon klien!

⚙️ Panduan Kustomisasi Saat Klien Deal

Jika klinik sudah setuju untuk pembuatan website resmi, sesuaikan bagian berikut di dalam index.html:

Hapus Banner Demo: Hapus elemen <div class="relative bg-slate-900 ...">LIVE DEMO TEMPLATE...</div> di bagian paling atas <body>.

Ganti Nomor WhatsApp Admin: Cari seluruh kemunculan nomor 628998702799 (pada variabel waNumber di <script> serta tautan https://wa.me/...) dan ganti dengan nomor WhatsApp resmi admin klinik (format kode negara 62 tanpa tanda + atau 0 di depan).

Sesuaikan Identitas Klinik: Ubah nama brand CikarangSmile, alamat ruko/klinik di bagian #lokasi, daftar harga layanan, serta nama dan jadwal praktik dokter sesuai data asli klien.

Hubungkan Domain Resmi: Pasang domain .com atau .co.id pilihan klien melalui pengaturan Domains di dashboard Vercel.
